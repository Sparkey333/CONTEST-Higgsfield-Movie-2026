# Wargame records

One file per concept, per run. Protocol: [`docs/10-wargame.md`](../../docs/10-wargame.md).

**Dead concepts stay here.** The reasoning outlives the ruling, and a concept killed in
August is a concept nobody re-proposes in a panic on the 27th.

Naming: `YYYY-MM-DD-<concept-slug>.md`
