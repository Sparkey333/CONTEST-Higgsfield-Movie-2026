## PHASE 2 · PRODUCTION — Aug 16–23 (T-15 to T-8)

The generation grind. **Run a rolling assembly from day one** — never wait until the
end to discover it doesn't cut together.

| Days | Work | Owner |
|---|---|---|
| Aug 16–17 | **Hook sequence first** (first 15s) — highest-value, most re-rolled | Phedon + Edwin |
| Aug 18–20 | Middle sequences | Phedon |
| Aug 20–22 | **Ending sequence** — the last 20s are what gets scored | Phedon + Edwin |
| Daily | Rolling assembly + drift check | Phedon |
| Daily | Campaign posts from real production material | Anderson |
| Aug 22 | Upscale / deflicker / cleanup pass | Phedon |
| **Aug 23** | **GATE 3 · Rough cut assembled end-to-end** | Catmull |

**Rules of the grind:**
- Never re-roll blindly. Diagnose *why* it missed: prompt, reference, or model choice.
- Chain shots — `end_image` of one becomes `start_image` of the next.
- Shoot the hook and the ending first. The middle can be salvaged; those cannot.
- Log every prompt as you go. It is a **required, scored deliverable** — not cleanup.

## Credit budget

**Current balance: 0. This is the top blocker.**

Rough planning model for a 4-minute film:

| Item | Estimate |
|---|---|
| Finished runtime | ~240s |
| Avg shot length | 5–8s |
| **Finished shots needed** | **~35–45** |
| Realistic re-roll ratio | **3–5×** |
| **Total generations** | **~120–200** |
| Plus character refs, tests, upscales, pickups | +30–40% |

**Recommendation:** 4,000 credits ($190, 44% off) as the working floor, with
auto-refill enabled so a run never dies mid-sequence. Reserve **~25%** of the budget
for pickups after Gate 3 — the rough cut always exposes shots that must be redone.

**Burn discipline:**
- Test cheap, finish expensive. Block sequences on Seedance 2.0 Mini or Veo 3.1 Lite,
  then commit final shots on the premium models.
- Never re-roll without a diagnosis.
- Track spend daily. Catmull raises the alarm at 60% burn before Gate 3.
