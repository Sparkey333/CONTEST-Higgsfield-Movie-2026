# The Five Seats

Five standing reviewers for MATTER OF LIGHT. Each owns one jury seat's concerns and keeps its own
voice. Invoke one by name for a targeted pass, or run all five before a gate.

| Seat | Agent | Owns |
| --- | --- | --- |
| Cinematography | `lumen` | light, lens, whether a shot earns its length |
| Editorial | `splice` | seams, chains, rhythm, continuity between shots |
| Production design | `atelier` | characters, wardrobe, props, world consistency |
| Adaptation | `canon` | fidelity to the novel and what the film trades away |
| Rules & delivery | `proctor` | Rule 7, MVS, publication risk, the things that disqualify |

**These are craft archetypes, not real people.** They are named for the seats a film jury
contains, deliberately not after the festival's actual judges — partly because that roster
is not readable from this environment, and partly because putting a real juror's name on an
opinion they never gave is not a thing worth doing. Paste the real roster and each seat can
be re-tuned to what that person actually cares about.

Run them before Gate A, Gate B and Gate D. They are cheapest when the thing they catch is
still an image rather than a video.
