02Getting it onto the Mac

Three routes, cheapest first. Route A is enough for most days. Route B is the one that gives you a Dock icon and its own window with no browser chrome around it.

A

Just open it

Double-click index.html. Every link is relative, so the whole desk works straight off the disk with no server running.

B

Install it as an app

Double-click Open Director Bible.command. First run only: right-click it → Open, because macOS blocks double-clicked scripts the first time.

Then Chrome or Edge → File → Install page as app. You get Production Desk in the Dock, in its own window, still working after you close the terminal.

C

Or run the server yourself

python3 -m http.server 8733 in this folder, then open http://localhost:8733.

—

Where your work is stored

Status log, ticked steps and vault keys live in browser local storage, which is per-origin. Opening from a file path and from localhost are two different origins, so they keep two separate sets of everything. Pick one route and stay on it.

The bible and this page share one vault, because they share an origin. Enter a key here and the bible already has it.

04Status read

Four screenshots, taken in this order, are enough to reconstruct exactly where the project stands — without you having to remember or describe it. Capture 1 alone answers most of it. Take the rest when you want the answer to be specific rather than approximate.

Everything below runs locally. The panel builds a hand-off block you paste into a chat alongside the images, keeps a dated log so the day-over-day delta is visible, and — if you have stored a Claude key in the vault — can send the read directly.

Step 1 · Capture
  • Full window, never a region. A crop hides the thing that was about to be the answer.
  • One screen per image. Two monitors in one file makes both unreadable.
  • Do not scale down on export. Filenames and counts are the payload — if they are not legible the capture was wasted. Cmd+Shift+4 then Space captures a single window cleanly.
  • Same set, same order, every time. The value is in the diff, and a diff needs the shots to line up.
Step 2 · Load themNo images loaded
Drop screenshots here or click to choose — PNG, JPEG or WebP. They never leave this machine unless you press Send.
Step 3 · What you already knowOptional — blanks are fine

Fill in anything you know off the top of your head. It is not a form to complete — it is context that makes the read sharper, and the counts are what the log charts over time.
