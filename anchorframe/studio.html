The setup questions

These sixteen questions are the Anchorframe intake: the same form starts every project in the template. Here each one carries a proposal written from what the project already knows. Accept it, change it, or ask Claude for a better one. Answers save as you type.

Uploads

Files stored with the studio, shared with everyone you invite. Up to 20 MB each: PDF, Markdown, plain text, CSV, JSON, images, MP4 and WebM.

Uploading needs the studio opened in claude.ai by someone who can edit it.

Ideas

Anything you want Claude to fold in: a scene idea, a line, a look, a change.

Higgsfield

The studio calls Higgsfield with your own connector: no keys, and it only ever sees this project, e6e807a9-49a8-41f1-bb4c-9247468606cb. Generations made here are filed into the project, the same folder the web app uses, so the two stay one place.

How making things works

  • Every Generate button asks Higgsfield for the cost first; nothing is spent until you press the button that shows the price.
  • Stills use nano_banana_2; video uses cinematic_studio_video_4_0 at 21:9.
  • Chained start and end frames, Souls and audio references still go through the web app: copy the lane's prompt there.
  • Whatever you make, assign it below to the sheet or shot lane it belongs to. That is what Claude reads on sync.
