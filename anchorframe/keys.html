anchorframe · keys

Bring your own keys

Every key on this page lives in this browser's local storage and nowhere else. Export writes a keys.env file for the command-line tools; that filename is gitignored. Nothing here is sent anywhere by this page.

Two rules. Never paste a key into a prompt, a commit, a screenshot or a shared page. If you ever have — rotate it at the link on its card; the old one is gone in seconds and nothing you built depends on it.

Generation

Higgsfield Cloud API

generate.py · SDK · every model in the catalogueget key ↗

Two values, an id and a secret. The SDK reads HF_API_KEY + HF_API_SECRET, or the pair joined as HF_KEY=id:secret. Model ids on this API are the Cloud names (bytedance/seedream/v4/text-to-image), not the web app's.

Higgsfield in Claude (MCP connector)

history pulls · batch generation · Virality Predictor · the route this desk was built onno key — connect in claude.ai

Connected as an integration to your Claude account, not with a key you hold. It is the only route that can page the account's generation history and run the Predictor; ingest.py reads the files those pulls write. Credits and the connection live at higgsfield.ai/mcp-credits.
