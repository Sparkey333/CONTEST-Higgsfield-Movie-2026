# Submission Checklist

*Run this per film. Target ship date: **Aug 29**, not Aug 31.*

---

## 1. Compliance — check these first, they are disqualifiers

- [ ] Runtime **over 3:00** (measured on the final export, credits included/excluded per verified rule)
- [ ] Runtime **under 5:00**
- [ ] Delivery spec matches the rules page: resolution ___ · aspect ___ · fps ___ · codec ___
- [ ] **Higgsfield watermark** present/handled per rule
- [ ] Made in compliance with the tool-exclusivity rule *(see rules verification log)*
- [ ] **No licensed music.** Original or royalty-free only. Every audio source documented.
- [ ] No third-party IP in frame — no logos, no recognizable brands, no real trademarks
- [ ] Entrant 18+, active subscription, team ≤ 4 and all members credited
- [ ] Film is standalone *(not a fragment of, or trailer for, another entry)*

---

## 2. The Film

- [ ] Watched **on a phone, sound off.** Does it still hold?
- [ ] Watched **on a phone, earbuds in.** Is the sub audible? Is dialogue/radio intelligible?
- [ ] Watched on a large screen. Does the grain hold up? Does anything look plastic?
- [ ] **The Turn is legible** — an outside viewer can point at the moment the character changed
- [ ] A hook, cut, or hard reversal lands inside the first **25 seconds**
- [ ] No shot betrays the three unbreakable Look Bible rules
- [ ] Character consistency holds — watch once looking *only* at the face
- [ ] Titles and end card are readable at phone size
- [ ] Final export has no dropped frames, no audio clicks at cut points

---

## 3. The Open-Source Package *(Platform Engagement — 15%)*

- [ ] README: logline, runtime, credits, one paragraph on the idea
- [ ] Snowflake docs, Steps 1–8
- [ ] Prompt cards, one per shot, locked fragments visible
- [ ] Look Bible with the three rules stated plainly
- [ ] The technical/subject-matter note *(the thing only you can write)*
- [ ] Keep-rate data — attempts vs. selections, honest numbers
- [ ] Framed and titled as a **tutorial**, not a file dump

---

## 4. The Campaign *(Social Engagement — 15%)*

- [ ] Hook clip #1 cut — silent-legible, 9–15s
- [ ] Hook clip #2 cut — sound-on
- [ ] Vertical versions exported for IG / TikTok
- [ ] Launch thread written *(hook → who you are → the real thing behind it → open-source link → film)*
- [ ] Build-in-public posts have been running since **Aug 11**, not starting today
- [ ] DarkHearts Ltd. bio and links live on every channel
- [ ] Press angle written as one sentence a journalist could file

---

## 5. Submit

- [ ] Submitted via the platform's **public post** mechanic
- [ ] Project files published
- [ ] Submission confirmed and screenshotted
- [ ] Hook clips live within one hour of submission
- [ ] Launch thread posted

---

## 6. Post-Submission

- [ ] Reply to every comment for the first 48 hours
- [ ] Cross-post to relevant communities
- [ ] Second entry status: ☐ shipped ☐ in progress ☐ cut

---
